# WORKSPACE DESIGN RULES: NOOR SALON & SPA

Refer to root `AGENTS.md` for authoritative tokens and anti-patterns.
- Color Tokens: `bg` (#FAF5F0), `blush` (#EBD3C7), `text` (#1A1614), `primary` (#1A1614), `champagne` (#C9A98A), `muted` (#8C7F78).
- Typography: Bodoni Moda (headings, italic contrast) + Jost (body & tracked labels).
- Shape: Radius 0, 1px champagne offset frames. No shadows, no gradients.
- Motion: Easing `[0.76, 0, 0.24, 1]`, 800-1000ms duration.
- Banned: No purple/blue gradients, no Inter/Roboto/Poppins, no emoji badges, no banned marketing clichés.
